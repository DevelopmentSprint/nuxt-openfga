## Install the package

::code-group
```bash [pnpm]
pnpm add @developmentsprint/nuxt-openfga
```

```bash [npm]
npm install @developmentsprint/nuxt-openfga
```

```bash [yarn]
yarn add @developmentsprint/nuxt-openfga
```
::

## Lift the axios version

`@openfga/sdk` pins an exact axios version with open security advisories
(`@openfga/sdk@0.9.7` pins `axios@1.19.0`; 1.20.0 fixes them). Until the SDK
updates it, lift it in your application. The module's tests pass against
axios 1.21.

::code-group
```yaml [pnpm-workspace.yaml]
overrides:
  axios: ^1.20.0
```

```json [package.json (npm)]
{
  "overrides": { "axios": "^1.20.0" }
}
```

```json [package.json (yarn)]
{
  "resolutions": { "axios": "^1.20.0" }
}
```
::

## Register the module

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@developmentsprint/nuxt-openfga'],
  openfga: {
    apiUrl: 'http://localhost:8080',
  },
})
```

Point it at your store and model:

```bash [.env]
OPENFGA_STORE_ID=01J...
OPENFGA_MODEL_ID=01J...
```

Every option can also come from an environment variable. See
[Configuration](/reference/configuration).

::tip
To try the module without an OpenFGA server, set `OPENFGA_MODE=memory` and
load a model as shown in [Memory mode](/guide/memory-mode).
::
