---
title: Authentication
description: Tell the module who the signed-in user is.
navigation:
  icon: i-lucide-key-round
---

The module does not authenticate users. It reads the signed-in user's id from
`event.context`, by default at `event.context.user.id`, and checks it as the
subject `user:<id>`.

Set that value in your own server middleware, or point `userIdPath` at
wherever your auth layer already puts it:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  openfga: {
    userIdPath: 'auth.session.userId', // reads event.context.auth.session.userId
  },
})
```

Requests without a user id are anonymous. `requireRelation` and
`/api/_authz/check` respond 401 to them.

::note
The UI checks only ever ask about the signed-in user. The check endpoint
ignores any subject sent in the request body, so a browser cannot ask about
someone else's access.
::
