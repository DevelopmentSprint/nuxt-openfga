## Server helpers

Auto-imported in Nitro server code. Helpers named with a bare `userId` add the
`user:` prefix; their `...ForSubject` forms take any OpenFGA subject, such as
`group:eng#member` or `user:*`.

### Checks and writes

| Function | Returns |
|---|---|
| `checkAccess(userId, relation, objectType, objectId, options?)` | `Promise<boolean>`, cached. |
| `checkAccessOrThrow(userId, relation, objectType, objectId, options?)` | Throws 403 on deny. |
| `listObjects(userId, relation, objectType)` | `Promise<string[]>` of `type:id`, not cached. |
| `writeRelationship(userId, relation, objectType, objectId)` | Writes a tuple and invalidates that object's decisions. |
| `deleteRelationship(userId, relation, objectType, objectId)` | Deletes a tuple and invalidates that object's decisions. |
| `checkAccessForSubject(subject, …)` and the other `...ForSubject` forms | Same as above, for any subject. |

`options` is `{ contextualTuples?: ContextualTupleKey[] }`. See
[Contextual tuples](/guide/contextual-tuples).

### Route guard

| Function | Description |
|---|---|
| `requireRelation(objectType, relation, getObjectId, getContextualTuples?)` | An `onRequest` handler that responds 401, 400 or 403. See [Server](/guide/server#route-guards). |

### Request context

| Function | Returns |
|---|---|
| `getAuthzUserId(event)` | The user id at `userIdPath`, or `undefined` when anonymous. Numeric ids are stringified. |
| `getAuthzContextualTuples(event)` | The tuples at `contextualTuplesKey`, or `undefined`. Throws when the value is not an array of tuple keys. |

### Cache

| Function | Description |
|---|---|
| `invalidateCache(userId, objectType, objectId)` | Drops one user's decisions on an object, across relations. |
| `invalidateCacheForSubject(subject, objectType, objectId)` | Same, for any subject. |
| `clearAuthzCache()` | Drops every cached decision. |
| `getAuthzCacheStats()` | `{ size, maxEntries, ttlMs }`. |

See [Caching](/guide/caching).

### Client and memory mode

| Function | Description |
|---|---|
| `useOpenFGAClient()` | The `OpenFgaClient`, or the in-memory client in memory mode. |
| `resetOpenFGAClient()` | Drops the client so the next call builds a new one. For tests. |
| `isMemoryMode()` | `true` when `OPENFGA_MODE=memory`. |
| `loadMemoryStore({ model, tuples? })` | Loads the in-memory store. |
| `resetMemoryStore()` | Empties the in-memory store. |

See [Memory mode](/guide/memory-mode).

## Composables and components

Auto-imported in the Vue app.

| Name | Description |
|---|---|
| `useCan(relation, objectType, objectId)` | `{ allowed, pending, error, refresh }`. Arguments may be refs or getters. |
| `<Can relation object-type object-id>` | Default slot when allowed, `#pending` while checking, `#fallback` otherwise. |

See [UI](/guide/ui).

## Endpoint

| Route | Description |
|---|---|
| `POST /api/_authz/check` | Checks a relation for the signed-in user. Used by `useCan` and `<Can>`. See [UI](/guide/ui#the-check-endpoint). |
